# Фотографии сайта

Все файлы нужны для сборки. Не удаляйте и не переименовывайте их без правки `src/data.ts`.

- `hero.webp` / `hero-clinic.jpg` — первый экран
- `about.webp` / `about-clinic.jpg` / `about-clinic.svg` — блок «О клинике»
- `cat-*.webp` и `direction-*.jpg` — карточки направлений
- `gallery-*.webp` — галерея
- `article-*.webp` — обложки статей

Сборка запускается **из корня проекта**, не из папки `src`:

```
cd C:\Users\roman\OneDrive\Desktop\demo
npm run build
```
